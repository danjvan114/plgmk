## 二、建议后端提供的动态接口（前端当前为模拟数据）

### 1. `GET /api/stats` — 项目数据实时指标（60s 短缓存）
前端位置：「项目数据」区块三张堆叠卡片 + 实时时钟。
```json
{
  "developers": 12000,
  "developersTrend": "+12.4%",
  "projects": 85000,
  "projectsTrend": "+18.2%",
  "posts": 128000,
  "postsTrend": "+3.2k",
  "todayPosts": 3218,
  "weekHeat": "9.6w",
  "totalLikes": "42w",
  "updatedAt": "2026-08-14T21:00:00+08:00"
}
```
字段说明：
- `developers / projects / posts`：三张卡片主数字
- `*Trend`：卡片右上角趋势角标
- `todayPosts / weekHeat / totalLikes`：第三张卡（发布帖子）的三个子进度条数值
- `updatedAt`：用于「数据实时更新」时钟的时间基准（可选）

### 2. `GET /api/release` — 最新版本与下载（缓存 5min）
前端位置：顶部 badge、Windows 下载卡、安卓下载按钮、更新记录。
```json
{
  "version": "1.2.4",
  "badge": "v1.3.0",
  "windows": { "url": "...", "size": "48MB", "sha256": "..." },
  "android": { "url": "...", "size": "25MB" },
  "releaseDate": "2026-08-10",
  "changelog": [
    { "version": "1.3.0", "notes": ["..."] },
    { "version": "1.2.4", "notes": ["..."] }
  ]
}
```

### 3. `GET /api/qrcodes` — 二维码清单（缓存 1h）
前端位置：二维码悬浮窗、桌面扫码弹层。
```json
{
  "mobile":  { "url": "https://...", "updatedAt": "..." },
  "qqgroup": { "url": "https://..." },
  "scan":    { "url": "https://..." }
}
```

## 四、适配注意事项

1. **多语言**：前端内置 6 语言（中文 / 繁体 / English / 日本語 / 한국어 / Español）。后端若提供动态文案，需按 `zh/tw/en/ja/ko/es` 六字段返回，或仅返回 key 由前端映射。
2. **主题资源一一对应**：3 套主题的 Logo / 背景 / 终端图必须配套，缺一张该主题下会显示空白。
3. **HTTPS**：所有资源地址必须 HTTPS，否则移动端（via/微信内）会拦截。
4. **二维码生成**：建议服务端动态生成（内容变更无需换图），白底、纠错等级 M 以上。
5. **版本一致性**：badge、下载文件名、更新记录三处版本号必须统一，避免用户困惑。
6. **接口容错**：前端对接口失败有降级（继续用当前模拟数据），后端接口超时建议 ≤3s。
7. **CORS**：若接口跨域，需允许前端域名；否则前端需通过同域网关转发。
