## ⚠️ 关键陷阱（改动前务必先看）

1. **编辑器下载.html 主脚本是一个大 IIFE**（`<script>` 从 RUN_ENV 到 `applyTheme()`），任何一处未判空就 `.addEventListener` 都会让**整页 JS 全灭**。新增/删除按钮时必须同步清理所有引用（弹窗互斥函数 showXxx 里互相 close 的那串也要清）。
2. **两页统一按钮 ID 约定**：`#themeBtn`（太阳/月亮开关，唯一主题入口）、`#adAvatarBtn`+`#adAvatarPop`（最右用户登录）、`#langBtn`、`#qrBtn`。不要再加 `lookBtn`/`themePop`/`perfPop`/`themeToggle`/`perfBtn`。
3. **插件市场.html 的 `--glass-nav` 变量同时被 `.icon-btn` 使用**：改顶栏透明度要直接覆盖 `#hv2 header` 的 background，不要动变量。
4. **headless 无 WebGL 环境会自动进 lite-mode**（关全部模糊），截图/计算样式验证时需剔除该分支，否则会误判"模糊没恢复"。
5. **本地预览**：直接双击打开即可；插件列表/用户头像的 fetch 会失败属正常（有降级）。验证方式：白天/黑夜各截图检查——顶栏贴顶 50% 透明且下滑不消失、编辑器卡片实心+有背景图+有模糊、黑夜下回到顶部按钮为白色。
