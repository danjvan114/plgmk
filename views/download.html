KN Expanse

KE 生态官方图形化编程 + 编辑器，与本站"作品池"深度整合，支持 ke/cue 双加载器。

本地直接双击运行；如被 Windows SmartScreen 拦截，请右键 → 属性 → 勾选"解除锁定"。

功能亮点
code
图形化编程
拖拽积木即可生成可发布的 KE / CUE 作品
extension
扩展加载器互斥
支持 KE 扩展与 CUELoader (cue.user.js) 互斥运行
cloud_upload
一键发布作品
编辑器内登录后，可直接推送到本站作品池
lock
作品加密 (auth/u)
可选加密模式，密文经 kauth.c(raw, u) 解密
使用方式

1. 下载并双击运行 KN Expanse.exe；

2. 在编辑器里完成作品，登录 KE 用户中心；

3. 点击"发布作品"，填写作品文件直链 f（必填）、可选 o/v/u/auth/auto 等播放器参数；

4. 提交后即可在本站 /workpool 查看并运行。
