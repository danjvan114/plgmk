# 黑莓计划｜BlackBerry Q20（Classic）引导锁底层安全研究项目

## 项目概述
项目代号：**黑莓计划**
研究目标机型：BlackBerry Q20 Classic（BB10平台），同步兼容拓展研究BB10系列其他机型（Q10、Z10、Z30、Passport）
研究方向：剖析BB10原厂Bootloader引导锁安全机制，探索可行底层访问方案，用于设备救砖、固件备份、嵌入式安全逆向实验。

黑莓BB10平台搭载企业级安全启动链，SBL+ABoot启动链路内置强制固件签名校验。厂商从未开放官方引导锁解锁通道。对比安卓Fastboot开放生态，黑莓底层防护闭环严密，不存在通用一键解锁方案。项目将两条技术路线并行验证：纯软件漏洞利用方案、硬件闪存直读调试方案。

### 路线一：软件层面漏洞挖掘
1. 梳理各版本BB10固件差异，筛选存在底层调试漏洞的早期系统版本；
2. 尝试建立PC与终端底层调试通信通道，寻找签名校验逻辑缺陷；
3. 局限性：漏洞存在版本限制，高版本固件官方已封堵安全缺陷，通用性弱，成功率较低；一旦系统升级补丁即失效。

### 路线二：硬件底层调试（主流研究方向）
1. 拆机定位主板测试点，引出UART调试接口或eMMC ISP直连通道；
2. 通过硬件读写器直接dump闪存完整固件镜像，离线逆向引导分区、安全校验模块；
3. 尝试修改底层引导配置，绕过Bootloader签名限制；
4. 风险提示：焊接、接线操作门槛高，接线错误、电压异常会直接烧毁主控与闪存，造成设备彻底报废。

## 项目研究价值
1. **设备救砖**：大量二手Q20因刷机失败卡死在引导界面，锁闭的Bootloader阻碍固件修复；解锁底层权限实现救砖恢复；
2. **固件归档**：完整备份原厂分区镜像，留存BB10绝版固件资源；
3. **安全学习**：研究企业级移动终端安全启动链、数字签名验证实现原理；
> 客观现实：即便成功解除引导锁，依旧难以移植第三方操作系统。BB10硬件驱动高度闭源，民间适配资源稀缺，项目不以刷第三方ROM为核心目标。

## 风险汇总
1. 操作失误→主板闪存损坏、永久变砖；
2. 底层修改导致安全校验崩溃，设备无法正常启动；
3. 网络大量虚假“一键解锁工具”捆绑恶意程序，威胁电脑安全；
4. 任何违规使用技术手段处理他人设备，将承担民事、刑事责任。
