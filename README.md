# KE Hub（plgmk）Node.js 版

KE Hub（原 CUELoader 插件市场）重构版。技术栈：**纯 Node.js（零 npm 依赖）**、纯 HTML + 原生 JS 渲染、**MDUI 1.0.2**（本地自托管 + 原站视觉风格）、KT 用户中心 SSO 统一登录。

> UI 说明：全站按你要求回归 mdui **1.0.2** 视觉风格（非 mdui2 自定义元素）。页面以纯 CSS 组件（`.btn/.chip/.seg-group/.ke-tabs/.text-input`…）+ `ripple.js` 涟漪（`class="mdui-ripple"` 即用，复刻 mdui1.0.2）实现，未引入 mdui2 组件。

## 快速开始

```bash
node server.js
# 访问 http://127.0.0.1:8897
```

仅需 Node.js ≥ 18，无任何第三方依赖与数据库安装。

`data/` 目录内是演示数据；要恢复全新站点，删除 `data/*.json`（保留目录）后重启即可，板块会自动重建。

## 登录（KT 用户中心 SSO）

点击「登录」会跳转到 `user.pgrm.top` 的用户中心授权页，同意后回跳本应用。本应用不保存密码；用户名（登录名）不可变，昵称/头像可随时在用户中心修改，公开展示一律用昵称。

### 需要在用户中心后台添加的白名单回调地址

| 环境 | 回调地址（回跳后会自动附带 login 参数） |
|---|---|
| 生产 | `https://code.pgrm.top/login/at` |
| 本地 | `https://127.0.0.1:8897/login/at` |

- 回调地址会按「协议 + 域名 + 端口 + 路径」在用户中心侧严格匹配，白名单请填上面**完整地址**（不要只填域名）。
- 本应用侧会自动按请求来源拼接回调地址：生产环境被反代到 `code.pgrm.top` 时即为上面的生产地址，无需改代码。

### 密钥配置

AES 密钥默认已写入 `config.js`，更推荐用环境变量覆盖（`.env` 或启动命令）：

| 环境变量 | 说明 | 默认值 |
|---|---|---|
| `PGMK_PORT` | 端口 | `8897` |
| `PGMK_HOST` | 监听地址 | `0.0.0.0` |
| `PGMK_USER_CENTER` | 用户中心地址 | `https://user.pgrm.top` |
| `PGMK_APPID` | 应用 ID（与用户中心注册一致） | `plgmk` |
| `PGMK_AES_KEY` | AES-256 密钥（hex） | 已内置 |
| `PGMK_AES_IV` | AES 偏移（hex） | 已内置 |
| `PGMK_CALLBACK` | 强制指定回调地址（可选） | 自动推导 |
| `PGMK_OWNER_NICKNAME` | 站点所有者身份判定的昵称 | `Starry` |
| `PGMK_SECURE_COOKIE` | 置 `1` 则 Cookie 加 Secure | `0`（本地 http 用） |
| `PGMK_DATA_DIR` | 数据目录 | `./data` |
| `PGMK_UPLOAD_DIR` | 上传目录 | `./public/uploads` |
| `PGMK_DEV_MODE` | 仅本地联调：开启后注册一个无 UI 入口的内部测试登录接口（见下文） | `0` |

`PGMK_SECURE_COOKIE`：正式站点若是 https 建议设 `1`；本地 `127.0.0.1` http 调试保持 `0`。

### 权限：超级管理员 / 巡查管理员 / 用户

站点**不预设演示账号**，一切权限在登录后**按身份字段实时判定**，用户信息以 KT 用户中心为准。界面统一不显示登录名，仅显示昵称；超级管理员自动获得 **KE 官方团队** 蓝V 徽标：

- **超级管理员（首位由昵称 `Starry` 自动识别，可再添加他人）**：昵称恰为 `Starry`（忽略大小写，`PGMK_OWNER_NICKNAME` 可改）的用户自动成为首任超级管理员并写入员工名单，具备完整权限：
  - 添加 / 移除**其它超级管理员**（super）与**巡查管理员**（admin）；
  - **禁用 / 启用任意** AI 机器人、**删除账号（封禁）**、设 **KE官方团队**/认证 UP 蓝V、审核「UP 主认证」与「加入我们团队」申请；
  - 具备巡查与硬删除能力；自动获得 KE 官方团队蓝V（verified=2）。
- **超级管理员（super，被首位超级管理员添加）**：自动获得 KE 官方团队蓝V；可巡查并**彻底删除**违规内容、**禁言/解除禁言**，但不能添加/移除管理员、不能删除账号、不能启停非本人机器人。
- **巡查管理员（admin，由超级管理员添加）**：可在「用户管理」看到**全部用户**并管理，执行删除违规内容、管理板块、发公告、**禁言/解除禁言**。
- **普通用户**：浏览、发布、评论、关注、@提及，在 `开发者中心` 自主添加/启用停用自己的 AI 机器人；可申请 **UP 主认证**（选平台 + 平台昵称 + 理由）或**申请加入 KE 团队**（加入理由 + 能带来什么），经超级管理员审核后分别授予 UP 蓝V / KE官方团队蓝V。

三种管理员入口都是右上角「管理后台」。「用户管理」对巡查管理员及以上全部开放（可见所有用户、禁言）；**仅首位超级管理员**看到「管理员设置 / AI机器人 / 认证审核」，以及「用户管理」里的封禁、设官方、认证操作。

> 禁言：到期自动解除，期间无法发帖/回复/评论/发布作品与插件。删除账号：该用户所有会话立即失效（被强制下线），前端会弹「您的设备已经被下线，请重新登录」。@提及他人会自动给对方发一条高亮（红）的 mention 通知并可点进直达帖子/作品。

### AI 机器人（自动回复）

**每个登录用户都能**在 `开发者中心 /dev → 我的 AI 机器人` 里添加自己的机器人（填 API 地址、Key、模型名、发帖账号、概率、冷却，先测后存）；首位超级管理员（昵称 Starry）与机器人本人可在后台**禁用/启用**机器人（全局开关）。

| 字段 | 说明 |
|---|---|
| 名称 | 机器人备注名 |
| API 地址 | 模型服务地址，如 `https://api.openai.com/v1`（缺省自动补 `/chat/completions`）；兼容任意 OpenAI 风格接口 |
| API Key / 模型名称 | 调用模型服务的密钥与模型名 |
| 发帖账号 | 该机器人在用户中心注册的**用户名**（昵称/头像可另填），回帖以此身份展示 |
| 人设提示词 | 可选，默认“论坛普通成员”人设 |
| 回复概率 | 0-100%，每次新帖/新回复按此概率决定是否抢答 |
| 冷却秒数 | 两次触发的最小间隔，默认 0 不限 |

- **连接通过才可保存**：新增/改动 API 地址、密钥或模型后，必须点「测试连接」成功才能保存；测试凭据 10 分钟内有效。
- 只要论坛出现**新帖子**或**新回复**，所有**已启用**的机器人都会独立收到完整内容（标题 + 作者 + 正文 + 板块），各自按概率回复；机器人不会回复机器人（避免死循环）；每次触发写入该机器人的「日志」。
- 演示数据内置一个 `stub://demo` 机器人（100% 概率，作者 starry_owner）便于本地查看效果；真实模型示例：地址 `https://api.openai.com/v1`、模型 `gpt-4o-mini`。

### 本地联调说明（生产请勿开 `PGMK_DEV_MODE`）

本应用**没有**任何“演示登录”按钮或界面（生产 UI 干净）。`PGMK_DEV_MODE=1` 仅在服务端注册一个**无 UI 入口**的内部接口 `POST /api/_dev/login {username,nickname}`，用于本地/脚本模拟登录以走通权限与上传链路；生产默认 `PGMK_DEV_MODE=0` 时该接口不注册、返回 404。令牌巡检对 `dev:` 前缀令牌跳过用户中心校验，仅在该模式下生效。

> 登录自检：登录后右上角应变为头像菜单（含「退出登录」）。若仍显示「登录」按钮，请清理 Cookie 后刷新。正式登录链路默认走 https://user.pgrm.top，需先在用户中心白名单加入回调地址。

### 端到端自测脚本

```bash
node scripts/final-check.js   # 需要先以 PGMK_DEV_MODE=1 启动：权限/机器人/持久化 21 项
node scripts/e2e-test.js      # 更早的登录/上传/发布/发帖链路自测（同样需 dev 模式）
```

## 核心机制说明

- **存储**：全部数据为内存索引 + JSON 文件原子落盘（写临时文件→rename），300ms 合并刷写，退出前强制保存；每小时快照，自动保留最近 5 份。点赞/评分等走内存 Set 索引，浏览计数 10s 批量合并，避免写放大。
- **会话与角色**：HttpOnly Cookie `pgmk_sid` + 服务端会话，有效期 30 天（解决关浏览器即掉线）。角色按登录身份实时解析：站点所有者（昵称 Starry）/ 超级管理员 / 巡查管理员 / 普通用户，登录后定时向用户中心巡检令牌，失效立即注销（防盗号）。
- **上传**：XHR 流式上传（进度/速度/ETA），单文件 ≤10MB，服务端边收边计数超限即断；仅允许白名单扩展名。上传不经过页面跳转。
- **评论计数**：论坛跟帖与作品评论统一在服务端维护，删除/隐藏同步回退计数，杜绝旧版双写漂移。
- **安全**：写操作全部 POST；登录限流；输入统一清洗后再渲染（前端一律转义）；不再有 eval、明文密码、GET 删除类接口。
- **AI 自动回复**：论坛出现新帖/新回复时把内容投给每个已启用的机器人（各自独立账号 + 模型 + 概率 + 冷却），回帖走同一套回复写入与计数逻辑，全程记录日志。

## 作品 · 播放器

作品详情页使用 iframe 嵌入 `/app/player/`（完整移植原 KN Expanse 播放器，含 KEloader.js / cue.user.js / crypto-js / mdui1.0.2 等）。发布/编辑作品时填五个参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `f` | ✓ | 作品文件直链，播放器 fetch 此 URL 加载作品内容 |
| `o` | × | 扩展加载器：`1`=KE 扩展（KEloader.js），`2`=CUELoader（cue.user.js）；互斥 |
| `v` | × | 扩展 URL 列表（每行一条），自动编码为 base64 的 JSON 数组 |
| `u` | × | 鉴权字符；勾选"开启加密"自动写入 `123456` |
| `auth` | × | 加密开关；开启后 f 拉取的密文经 `window.kauth.c(raw, u)` 解密 |
| `auto` | × | 自动播放；开启后自动跳过 CoverMask 开始运行 |
